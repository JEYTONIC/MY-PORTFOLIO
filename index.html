MacknonBoda-Boda Boda -Hail Application

MacknonBoda is a ride-hailing platform designed to connect passengers with boda-boda riders in Mackinnon Road, Kwale County, Kenya, and surrounding communities. The platform aims to make local transportation more accessible, convenient, affordable, and reliable, especially in underserved neighbourhoods.

Key Features

  • On-demand ride booking
  • Rider discovery and matching
  • Real-time ride tracking
  • Transparent fare estimation
  • Multiple payment options (M-Pesa, cash)
  • Rider verification and passenger ratings
  • Dedicated interfaces for passengers and riders
  • Administrative dashboard for managing users, rides, and operations

Tech skack: React Native, Expo, TypeScript, React, NestJS, Node.js, PostgreSQL, and WebSockets.
Project Status: In Development.
